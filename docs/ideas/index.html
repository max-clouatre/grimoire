Making Grimoire real

Ideas for turning today's proof of concept into something we pursue · drafted by Claude, Oct 2 · stars, statuses, plan and votes on this page save to Grimoire/docs/ideas/ideas.json

Agents already do their work in files. Grimoire makes that work visible, steerable and shared: a live window onto a project's real state, where you and your agents edit the same things.

01Why this could matter

Chat is the wrong container for work. Agent output scrolls away. Plans, boards, decisions and status get rewritten from scratch each session or lost entirely. People keep the real state in their heads.
Agents are file-native; humans aren't. An agent happily keeps docs/board.kanban.json current, but nobody reads JSON. Grimoire is the translation layer, and it works both ways: you click, a file changes, the agent sees it.
Trust is the bottleneck, not capability. As agents run longer and in parallel, the question shifts from "can it do it?" to "what did it do, and what does it need from me?" A glanceable surface answers that without reading transcripts.
The unfair advantage of files-first: no lock-in, no integration work, and it's already where the agent is. Every harness that can write a file can drive grim today, and everything it shows is plain text in git.

02Who it's for first

Start narrow: people already working with coding agents every day, who feel the "what is my agent doing?" pain most.

The agent-heavy solo dev

Runs Claude Code or Codex all day on 2–5 repos. Wants to glance at what changed, what's blocked and what's next without scrolling chat. Our wedge.

The tech lead

Reviews agent and human work across a small team. Wants status, decisions and review queues that stay true on their own.

The builder-PM

Writes PRDs and roadmaps, ships with agents. Wants docs that are live, not stale wiki pages.

05Where we sit

09If it becomes a business

Free foreverThe local tool, skill, viewers and themes. MIT. Everything single-player.
TeamHosted share links, comments, sync across machines, SSO. Priced per seat, like any dev tool that grew up.
EcosystemA gallery of viewers and themes; maybe premium packs. More about reach than revenue.

Honest note: the business is the least certain part. The first 90 days are about whether people (starting with us) can't do without it.
